## 1. 模式 1 · MACD 12/26/9 柱 + 上下界 (④)

### 1.1 計算

- `hist` = MACD(12, 26, 9) 的柱 (DIF − DEA), 1× 柱 (牛牛 / Webull 顯示 2×)。
- `histPct = hist / close × 100` — 柱高以「收盤價的百分比」計, 換標的、換價位都免手調。
- 淺紅柱 = 負柱但比前一根縮短 (`hist < 0 and hist > hist[1]`) = 跌勢動能減低; 淺綠柱 = 正柱但比前一根縮短 (`hist > 0 and hist < hist[1]`) = 升勢動能減低。副圖柱的顏色深淺與此一致。
- 同號柱段統計 (⑥): 柱一換符號就重新起算 — 段內根數 `curBars`、段內最深 |柱| `curDepth` (%)、段內 Σ|柱| `curArea` (%·根)。判斷訊號時用「上一根為止」的快照 (`segBars / segDepth / segArea / segSign`), 先評估後更新, 無前視。

### 1.2 上下界 (畫在副圖柱上: 上界 紅線 / 下界 藍線)

| 參數 (④) | 預設 | 意思 |
|:---|:---|:---|
| 上下界模式 `thMode` | 自動(百分位) | 自動 = 由最近 N 根 \|柱\| 的分佈定; 手動 = 填死數 |
| 自動: 取樣根數 `pctLen` | 250 | 250 根 1 分 K ≈ 4 小時 |
| 自動: 基準 = \|柱\| 第幾百分位 `depthPctl` | **75** | 基準 = 最近 250 根 \|histPct\| 的第 75 百分位 → 只有最深的 25% 柱才算「到界」。舊版 50 = 一半柱都算, 所以幾乎每第二根淺紅都有訊號 |
| 自動校準係數 `kEff` (④b) | 1.0 (校準預設關) | 若開啟「目標每日交易次數」, 逐日乘上去 |
| 買 · 下界倍數 `kBuy` | **1.5** | 下界 = 基準 × 1.5 (買方要求更深; 0 = 不要求到界) |
| 賣 · 上界倍數 `kSell` | **1.0** | 上界 = 基準 × 1.0 (0 = 不要求到界) |
| 手動: 基準 `minDepthIn` | 0.35 % | 只在手動模式用 |

公式:

```
baseDepth = 自動 ? percentile(|histPct|, 250, 75) × kEff : minDepthIn     (單位 %)
minDepthB = baseDepth × kBuy        下界深度 (%)      band1Lo = −minDepthB / 100 × close   (畫在副圖的藍線)
minDepthS = baseDepth × kSell       上界深度 (%)      band1Up = +minDepthS / 100 × close   (畫在副圖的紅線)
```

### 1.3 模式 1 買訊 (單根事件) — 全部同時成立

1. 觸發方式 `trigMode` = 動能減弱 N 根 (預設): 本根是負柱段中**連續第 N 根淺紅柱** (`nFadeDn == fadeBuy`, 預設 N = 2), 只在剛好第 N 根那一根觸發一次。(可切「快慢線交叉」= DIF 上穿 DEA, 舊版)
2. 上一根為止仍是負柱段 (`segSign == −1`)。
3. **跌到下界**: 該負柱段內最深的柱 `segDepth ≥ minDepthB` (即柱曾經穿到藍線以下)。`kBuy = 0` 時不檢查。
4. 段內連續根數 `segBars ≥ mbBuy` (預設 4)。
5. (可選, 預設關 `useArea`) 段內面積 `segArea ≥ minDepthB × mbBuy × areaFactor (0.5)`。

副圖: ▲ 淺藍標在該根負柱底下; 未到界而被拒的淺紅 N 根可開 `showRejM1` 用灰色小三角對照。

### 1.4 模式 1 賣訊 (單根事件) — 全部同時成立

1. 本根是正柱段中**連續第 N 根淺綠柱** (`nFadeUp == fadeSell`, 預設 N = 2)。
2. 上一根為止仍是正柱段 (`segSign == +1`)。
3. **昇到上界**: 該正柱段內最高的柱 `segDepth ≥ minDepthS` (柱曾穿到紅線以上)。`kSell = 0` 時不檢查。
4. 段內根數 `segBars ≥ mbSell` (預設 3)。
5. (可選) 面積門檻同上。

副圖: ▼ 淺紅標在該根正柱頂上。

### 1.5 模式 1 訊號的有效期

- 買訊觸發後保持 `matchWin` 根有效 (④c, 預設 5): `m1Age` 觸發那根 = 0, 之後每根 +1, `m1Live = m1Age < matchWin`。
- 賣訊觸發後保持 `matchWinS` 根有效 (預設 5): `s1Live = s1Age < matchWinS`。

## 2. 模式 2 · RSI 14 / 28 可買區 / 可賣區 (④c) — 狀態, 不是買賣點

### 2.1 計算

| 參數 (④c) | 預設 | 意思 |
|:---|:---|:---|
| RSI 快線長度 `rsiFastLen` | 14 | 轉勢與到界都看它 (`rsiF`) |
| RSI 慢線長度 `rsiSlowLen` | 28 | 只用來與快線比較交叉, 決定區間何時結束 (`rsiS`) |
| 下界 / 上界怎麼定 `rsiBandMd` | 動態: 最近 N 根 RSI14 的百分位 | 固定 30 在 SOXL 1 分 K 很少碰到 (RSI14 常常最低只到 32); 動態界貼著實際分佈走。可切「固定: 30 / 70」 |
| 動態: 取樣根數 `rsiPctLen` | 120 | 120 根 1 分 K = 2 小時 |
| 動態: 下界百分位 `rsiPctLo` | 10 | 下界 = 最近 120 根 RSI14 的第 10 百分位 |
| 動態: 上界百分位 `rsiPctHi` | 90 | 上界 = 第 90 百分位 |
| 固定: 下界 / 上界 `rsiFixLo / rsiFixHi` | 30 / 70 | 固定模式用; 動態模式暖身期間 (不足 120 根) 也用它們 |
| 轉勢前幾根內曾到界 `m2Reach` | 1 | 1 = 轉勢那根的谷底 / 峰頂本身要在界外; 2–3 = 容許谷底前幾根曾到界 |
| 可買區何時結束 `zoneEndMd` | RSI14 跌破 RSI28, 或 RSI14 跌破進區時的谷底 (反彈失敗 = 昇不上) | 另兩種: RSI14 轉勢向下 (區間最短, 一個小回落就結束) / RSI28 轉勢向下 (區間最長) |
| 每個交易日開始時清空區間 `m2ResetDay` | 開 | 不把昨日收市前的可買區 / 可賣區帶到今日開市 (RSI 會跨越隔夜跳空) |
| 持倉中可買區結束 → 平倉 `m2ExitOnEnd` | 開 | 出場原因 M2區結束 |

轉勢的定義 (梯度變號, 谷底 / 峰頂在前一根, 本根收盤確認):

```
turnUpF = rsiF > rsiF[1] and rsiF[1] <= rsiF[2]     RSI14 梯度由 ≤0 轉為 >0 (轉勢向上)
turnDnF = rsiF < rsiF[1] and rsiF[1] >= rsiF[2]     RSI14 梯度由 ≥0 轉為 <0 (轉勢向下)
turnUpS / turnDnS                                     RSI28 同樣定義
reachLoF = (RSI14 上一次 ≤ 下界 距前一根幾根) < m2Reach   → m2Reach = 1 時就是「前一根 (谷底) 本身 ≤ 下界」
reachHiF = (RSI14 上一次 ≥ 上界 距前一根幾根) < m2Reach   → 「前一根 (峰頂) 本身 ≥ 上界」
xFSdn = RSI14 跌破 RSI28 (crossunder);  xFSup = RSI14 升穿 RSI28 (crossover)
m2Trough = 進入可買區那一根的谷底 (rsiF[1]);  m2Peak = 進入可賣區那一根的峰頂
```

### 2.2 進入可買區 (單根事件 `m2BuyStart`)

`turnUpF and reachLoF` — RSI14 轉勢向上, 而且轉勢的谷底到達或低於下界。從這一根開始 (含) 就是可買區。

### 2.3 可買區結束 (`buyEndRaw`, 「昇不上」)

- 預設: `xFSdn or rsiF < m2Trough` — RSI14 跌破 RSI28 (反彈後失守慢線), 或 RSI14 跌破進區那一根的谷底 (反彈失敗, 區間的前提已破)。單純一根小回落不會結束區間。
- 選項 2: `turnDnF` — RSI14 一轉勢向下就結束。
- 選項 3: `turnDnS` — RSI28 轉勢向下才結束。

### 2.4 進入可賣區 (單根事件 `m2SellStart`) — 相反原理

`turnDnF and reachHiF` — RSI14 轉勢向下, 而且轉勢的峰頂到達或高於上界。

### 2.5 可賣區結束 (`sellEndRaw`, 「跌不下」) — 相反原理

- 預設: `xFSup or rsiF > m2Peak` (RSI14 升穿 RSI28, 或升破進區時的峰頂); 選項 2: `turnUpF`; 選項 3: `turnUpS`。

### 2.6 狀態機 (每根依序判斷, 先到先算)

```
m2State: 1 = 可買區, −1 = 可賣區, 0 = 無
if 新交易日第一根 且 m2ResetDay → m2State := 0   (先清空, 不算「結束」)
if 進入可買區          → m2State := 1, 記下谷底 m2Trough   (進入新區優先於現區結束)
else if 進入可賣區     → m2State := −1, 記下峰頂 m2Peak
else if 在可買區 且 可買區結束條件 → 0
else if 在可賣區 且 可賣區結束條件 → 0
m2InBuy  = m2State == 1      模式 2 的輸出 (狀態)
m2InSell = m2State == −1
m2BuyEnd = 上一根在可買區 而 本根不在 (含直接轉入可賣區)   → 觸發持倉平倉
```

副圖 (TV-1M-RSI-mode2): 深棕粗線 RSI14、橙細線 RSI28、綠 / 紅細線 = 下界 / 上界、底色 淺藍 = 可買區 / 淺紅 = 可賣區、▲ 淺藍 = 進可買區、▼ 淺紅 = 進可賣區、× 小叉 = 區間結束、圓點 = 快慢線交叉 (藍 升穿 / 紅 跌破)。右上表: 現況、RSI14/28、上下界、轉勢向上 → 到下界才算 (次數)、窗內可買區 / 可賣區 K 數、交叉次數。

## 4. 模式 4 · EMA9 斜率 (④e) — 狀態, 只限制買入

| 參數 | 預設 |
|:---|:---|
| EMA 長度 `m4EmaLen` | 9 |
| 斜率取幾根 `m4Look` | 1 (EMA 現值 − 1 根前 > 0 = 向上) |
| 啟用 `useM4` | 開 |

```
m4Slope = (EMA9 − EMA9[m4Look]) / EMA9[m4Look] × 100     (%)
m4Up    = m4Slope > 0                                        趨勢向上 = 可以買入
m4OK    = not useM4 or m4Up                                  模式 4 的輸出 (狀態)
```

## 5. 合格買點 = 四模式同時 (⑨ 下單)

```
buyCore = m1Live and m3Live and m2InBuy            模式 1、3 的買訊都在 matchWin (5) 根內  且  模式 2 處於可買區
buyEvt  = m1Buy or m3Buy or m2BuyStart             本根至少一個模式「剛出現」買點
buySig  = buyCore and m4OK and (buyEvt or m4Start) 再加 模式 4 向上 (EMA9 剛轉向上也算剛出現)
下單    = buySig and 在回測期間 and 盤中 and 非 15:45 後 and 非 15:58 後 and 目前無倉
成交    = 下一根開盤 (含滑點), 全部本金
```

也就是: 買入那一根同時滿足 (1) 模式 1 買訊在 5 根內出現過; (2) 模式 3 金叉在 5 根內出現過; (3) 模式 2 在可買區; (4) EMA9 向上; 而且四者之中至少一個是本根剛發生的 (否則同一組條件會在窗口內重複觸發)。
